About the System

Expense Tracker is a web-based application designed to help users record their daily expenses, manage budgets, set goals, and monitor their spending habits. The system provides an organized and simple way to keep track of personal finances through an easy-to-use dashboard.

Features

  • ✅ Add and manage expenses
  • ✅ Categorize expenses
  • ✅ Set budgets for expenses
  • ✅ Generate expense reports
  • ✅ Set goals to achieve
  • ✅ A calendar to track dates
